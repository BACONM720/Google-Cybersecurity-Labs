# 🛡️ Google Cybersecurity Professional Certificate — Portfolio & Labs

![Google Cybersecurity Certificate](assets/certificate-badge.png)

## 📌 Overview
This repository contains my portfolio projects, lab write-ups, incident reports, and code developed during the **Google Cybersecurity Professional Certificate** program.

The program covered key cybersecurity concepts, tools, and hands-on scenarios across 8 courses, focusing on threat detection, risk management, incident response, network monitoring, and security automation.

---

## 🛠️ Skills & Tools Demonstrated

* **Operating Systems & Command Line:** Linux (Ubuntu/Bash), Windows
* **Networking & Packet Analysis:** TCP/IP, Wireshark, Tcpdump, Network Protocols
* **SIEM & IDS Tools:** Chronicle SIEM, Suricata
* **Programming & Scripting:** Python (File I/O, Algorithms, String manipulation), Bash
* **Security Frameworks:** NIST Cybersecurity Framework (CSF), Incident Response Lifecycle
* **Databases:** SQL (Data filtering, JOINs, security auditing)

## 📁 Repository Structure & Lab Summaries

### 🟢 [01 - Foundations of Cybersecurity](./01-foundations-of-cybersecurity)
* **Core Focus:** CISSP principles, security domains, and incident response basics.
* **Key Lab:** Incident Handler Journal entry detailing response steps to a mock security event.

### 🟡 [02 - Managing Security Risks](./02-managing-security-risks)
* **Core Focus:** NIST CSF (Identify, Protect, Detect, Respond, Recover), risk assessment.
* **Key Activity:** NIST CSF Analysis Report analyzing organizational risk exposure.

### 🔵 [03 - Networks & Network Security](./03-networks-and-network-security)
* **Core Focus:** OSI & TCP/IP models, packet sniffing, firewalls, and hardening.
* **Key Activity:** TCP/IP Packet Capture Analysis using Tcpdump logs to identify suspicious traffic.

### 🐧 [04 - Linux & Bash](./04-linux-and-bash)
* **Core Focus:** Linux CLI, user permissions (chmod/chown), Directory management.
* **Key Activity:** [Linux File Permissions Audit](./04-linux-and-bash/linux-file-permissions-audit.md) — Audited and modified directory/file access permissions to align with least privilege principles.

### 🟣 [05 - Assets, Threats, & Vulnerabilities](./05-assets-threats-vulnerabilities)
* **Core Focus:** Vulnerability management, threat modeling, attack surfaces.
* **Key Activity:** Vulnerability Assessment Report evaluating system exposure and remediation strategies.

### 🚨 [06 - Sound the Alarm: Detection & Response](./06-sound-the-alarm-detection-response)
* **Core Focus:** SIEM log investigation, intrusion detection systems (IDS).
* **Key Activity:** [Suricata Alert Analysis](./06-sound-the-alarm-detection-response/suricata-alert-analysis.md) — Analyzed network traffic signatures to detect potential port scans and unauthorized network activity.

### 🐍 [07 - Python Automation for Cybersecurity](./07-python-automation)
* **Core Focus:** Python automation, file processing, conditional logic.
* **Key Activity:** [IP Address Allow-List Algorithm](./07-python-automation/python-scripts/import_allow_list.py) — Created a Python script to parse a text file containing IP addresses and remove revoked access IPs automatically.

### 🏁 [08 - Capstone Project](./08-put-it-to-work-capstone)
* **Core Focus:** Comprehensive cybersecurity audit and incident response simulation.
* **Key Activity:** Incident Response Case Study — Completed an end-to-end incident report detailing initial compromise, containment steps, and post-incident recommendations.
